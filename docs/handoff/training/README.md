# Training guides

One short guide per role. Each fits a 30–45 minute session: demo it live, then have people try the
examples with their own jobs.

| Guide | For |
|---|---|
| [csr.md](csr.md) | Customer service reps |
| [prepress.md](prepress.md) | Prepress operators and leads |
| [estimating.md](estimating.md) | Estimators |
| [admin.md](admin.md) | IT / Switch / Pace administrators |

Rules that apply to everyone:
- **Claude drafts; you decide.** Read every customer message before sending it. Nothing goes to a customer
  automatically.
- **Check anything surprising** in Switch or Pace directly, and report it (see "Reporting problems" in each guide).
- **Customer files stay in the allowed folders.** Don't paste customer data into other AI tools.
